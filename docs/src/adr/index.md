# Architecture Decisions

Each Architecture Decision Record (ADR) states one decision about the protocol: its context, the
decision, the alternatives considered, and its consequences. Newer ADRs supersede older ones; an
ADR's Status section says whether it is `Proposed`, `Accepted`, `Rejected`, `Deprecated`, or
superseded, and links its successor.

[ADR 1](./0001-record-architecture-decisions-as-adrs.md) defines the process.
